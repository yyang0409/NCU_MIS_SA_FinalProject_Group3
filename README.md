# 呱呱WAWA Crowdfunding Platform

## Overview

**呱呱WAWA Crowdfunding Platform** is a web-based application developed as the final project for the Systems Analysis and Design course at National Central University. The platform enables users to create and support crowdfunding projects, facilitating the realization of innovative ideas through community funding.

> 📘 This project was developed as part of an academic course to explore the design and implementation of web-based crowdfunding systems.

## Features

- **Project Creation**:  
  Users can create crowdfunding projects, detailing their ideas, funding goals, and timelines.

- **Project Support**:  
  Supporters can browse and contribute to projects they find appealing.

- **User Authentication**:  
  Secure registration and login system for project creators and supporters.

- **Project Management**:  
  Project creators can update project statuses and communicate with supporters.

## System Requirements

- **Backend**: Java (Servlets)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
- **Development Environment**: Eclipse EE with Apache Tomcat server
